JavaScript Projects

JavaScript is a versatile programming language that allows developers to create interactive and dynamic web applications. Here are some of the JavaScript projects I have worked on:

Projects

  • Project 1: Create a game

    In this project, I created a simple game using JavaScript and HTML5 Canvas, for a project in hackclub called "Sprig". I learned about game development and user interaction. To play the game you must use the A, D, W and S keys to move around. The goal is to collect all the items while avoiding obstacles. To collect the items you must drive the item to the house.

  • Project 2: Create an animated scene

    In this project, I created an animated scene using JavaScript and HTML5 Canvas. I learned how to animate elements and create interactive experiences.

  • Project 3: Side Scroller in Code.org

    In this project I used collision, key and mouse inputs to make a game. To play the game you must use the arrow keys to move around. Of the frog touches the mashrooms then a life will be lost. You can also use the spacebar to jump.
